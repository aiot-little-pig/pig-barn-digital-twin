## 비교 우선순위

1. 「멘토링 후 방향성 재탐색」 2·4쪽의 한돈혁신센터, 중앙배기·세정 설비와 예측 중심 시연 방향.
2. 「방향성 재설계 및 관련 시스템, 데이터셋 조사」 1·2쪽의 무창돈사, 고정 팬, 설계 입기구, 내부 폐루프.
3. 같은 문서의 Lely Discovery Collector / JOZ Barn-E PRO, 그리고 재탐색 문서의 제주 AIoT·ICT 악취관리 사례를 기능 비교 대상으로 검토.
4. 빈 부분은 제조사 공식 설비 설명과 축산 기술자료로 보완. 일반 돈사 자료가 위 문서의 비교 대상을 대체하지 않도록 했습니다.

## 채택한 구조

무창·기계환기·중앙집중 배기형 육성·비육 사육실의 개념 모형입니다. 중앙 관리 통로 양쪽에 군사 돈방을 두고, 내부 기계환기 계통의 끝에 배기 세정 설비를 연결했습니다. 12×18 m, 통로 1.2 m, 6개 돈방, 부분 슬랫 비율 48%는 모두 이번 구현의 설계 가정입니다. 한돈혁신센터 실측값이 아닙니다. 바닥·급이·급수 상세는 아래 보완 자료에서 원리를 확인했으며 센터와 동일한 설비 배치를 확인했다는 뜻은 아닙니다.

기류 계통의 표현:

측벽 조절 입기구 → 사육실 → 천장 부근 수집구·중앙 덕트 → 고정 팬 → 배기 세정 설비 → 시스템 경계.

개별 사육실에서 하나의 중앙 덕트로 수집하는 단순화입니다. 실제 대형 농장의 여러 사육실·공용 배기실·설비 용량을 모두 복제한 것은 아닙니다. 화살표는 계통을 설명하며 기류속도/압력/CFD 결과가 아닙니다. 외기 자체를 모델링하지 않아도 환기를 표현하려면 들어오는 공기와 나가는 공기의 경계는 필요합니다. 민가·지형·외부 확산장을 복원하지 않았습니다.

## C4에서 바로잡은 물리적 가정

[제조사 배기 세정 설명](https://www.bigdutchman.com/en/news-stories/article/most-systems-work-like-a-washing-machine/)에서 중앙으로 모은 배출 공기를 팬으로 세정장치에 통과시키는 구조를 확인했습니다. 이를 반영하여 이전의 ‘실내 처리·재순환을 가정하면 가장 빠른 회복’ 설명을 기본 구조에서 제거했습니다.

C4의 팬+스크러버 동시 가동 조건은 유지합니다. 다만 배출용 스크러버는 동일 환기량일 때 실내 NH₃를 추가로 직접 제거하는 장치가 아니므로, C3보다 실내 회복이 빠르다고 자동으로 설정하지 않습니다. 이것은 구조에서 도출한 판단이며 저감 성능 실험 결과가 아닙니다. 실제 장치에서는 압력손실로 팬 운전점이 달라질 수 있으므로 팬 RPM을 곧바로 동일 환기량으로 해석해서도 안 됩니다.

향후 ‘C4가 실내에서 가장 우수함’을 비교하려면 별도의 실내 공기 처리 장치·오염원 제거 조치 또는 측정된 환기량 차이 같은 근거가 필요합니다. 그 조건을 확보하기 전에는 C4의 실내 우위를 ‘미검증’으로 표시합니다.

## 차별성 표현에 대한 정리

우리 팀의 검증 목표는 ‘비전 기반 표면 오염 정보+30분 후 실내 NH₃ 예측+불확실성을 고려한 선제 제어’입니다. 상용 장치가 모두 센서가 없거나 예측을 하지 않는다고 일반화하지 않습니다. 또한 카메라로 확인한 표면 분뇨 면적만으로 슬랫 아래 피트의 분뇨량이나 NH₃ 발생률이 직접 측정되는 것은 아닙니다. 관측 가능한 표면 정보와 관측되지 않는 하부 발생원을 구분해야 합니다.

원문 특허의 유효성·권리 범위·‘특허 공백’ 주장과 모델 성능 수치는 이번 구조 수정 범위에서 검증하지 않았습니다.

## 남은 실제 시설 정합성

현재 결과는 출처를 추적할 수 있는 구조 개념 모형입니다. 매우 유사한 배치 원리를 구현했지만 실측 디지털 트윈이라고 부를 수는 없습니다. 특정 농장과 일치시키려면 사육 단계/체중/두수, 평면·단면도, 입기·팬 배치와 성능 곡선, 세정장치 압력손실, 분뇨 배출 방식, 센서 좌표, 카메라 캘리브레이션을 받아야 합니다. 현재 코드는 이 값들을 추가할 수 있도록 구조 설정을 분리했습니다.
