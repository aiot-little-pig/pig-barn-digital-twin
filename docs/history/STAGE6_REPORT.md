# 6단계 — 실행본·모델 연결 인계

2026.10.12

## 결과

시뮬레이터의 1~6단계 구현을 마무리했다. **표준 규격의 실제 모델·데이터를 연결하고 대조할 수 있는 상태**다. 실제 학습모델의 성능 및 현장 효과까지 검증한 것은 아니다.

| 전달 항목 | 사용법 |
| --- | --- |
| `start.cmd` | FastAPI와 빌드된 화면을 함께 실행. READY 후 http://127.0.0.1:4173 접속 |
| `status.cmd` | 실행기 세션·준비 상태·공급 모드 확인 |
| `stop.cmd` | 이 실행기가 시작한 화면/API 종료 |
| `launcher.*.example.json` | Mock / 파일 / HTTP 모델 설정 예시 |
| `RUNBOOK.md` | 재실행, 새 PC 설치, 종료, 장애 확인 |
| `MODEL_HANDOFF.md` | 모델 담당자가 제공할 정보와 연결 완료 기준 |
| 전달용 ZIP | 빌드·소스·예시·문서 및 파일별 SHA-256 목록 |

시작 터미널을 유지하며, 종료는 stop.cmd 또는 Ctrl+C를 사용한다. 포트 8000/4173이 이미 사용 중이면 시작을 거부한다. 실행 로그는 `.runtime/api.log`에 남는다. 인증 토큰은 서버 환경변수로만 전달한다.

## 검증

- 시작 → 상태 조회 → Mock 예측 12 ppm → 종료 → 재시작을 두 차례 통과.
- 사용 중인 포트에 중복 시작해도 기존 서비스 유지. 종료 후 두 포트 해제 확인.
- 화면 서버는 dist만 제공. 소스·상위 경로·디렉터리 목록 접근 거부 및 잘못된 종료 토큰 거부 확인.
- 기능 기준: 5단계에서 JavaScript 38개·Python 15개 및 프로덕션 빌드 통과. 이번 단계에서 예측/평가 수식은 변경하지 않았다.

## 모델 담당자 인계 후 남는 일

1. 실제 데이터의 컬럼·단위·시간대·대상 ID를 계약에 맞춘다.
2. 입력 창·전처리·결측 규칙과 모델 API를 연결한다. 표준 규격과 다르면 서버 어댑터 매핑이 필요하다.
3. 실제 평가셋에서 예측값·구간·농장별 지표가 담당자 계산과 일치하는지 확인한다.
4. 위험 기준·센서 위치 등 미확정 정보는 근거를 받아 설정한다.

신규 센서 실측·외부 확산·공개 링크·로그인·실물 제어는 이번 실행본 범위에 포함하지 않는다. 10/14에는 연결 검증을 마치고 기능을 동결하며, 10/15에는 제출 전 실행 확인과 치명 오류 수정만 진행한다. 모델이 늦어지면 Mock임을 표시한 검증본을 보존한다.

최종 실행기로 Chrome 통합 검증 통과: 실제 FastAPI 연결, 농장·센서 전환, 되감기, 구간 경계, 가상 제어 검토, API 실패/재시도, 요청 중단, 잘못된 응답, 8초 제한 시간과 복구, 모바일 배치. 화면 오류 0건. 테스트 후 두 서비스 종료 확인.

전달용 ZIP을 별도 폴더에 풀어 91개 파일의 SHA-256과 압축 무결성을 대조했다. 추출된 소스·빌드·예시로 시작 → 화면/API 조회 → Mock 예측 → 종료를 통과했다. 이 검증은 기존 Python 런타임을 재사용했으며, 다른 PC에서의 최초 의존성 다운로드·설치는 검증하지 않았다.
