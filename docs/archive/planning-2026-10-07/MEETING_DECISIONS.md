# 팀 최종 회의 전 검토표

작성 기준: 2026-10-07. 아직 결정되지 않은 안건을 기록하기 위한 초안입니다. 권장안과 확정 결정을 구분합니다. 팀원 배정·일정·모델·성능 목표를 임의로 확정하지 않았습니다.

## 1. 현재 공유할 결론

- 사용자 요청으로 정해진 범위: 하드웨어 축소모형과 외부 확산 재현 제외, 돈사 내부 NH₃ 예측·제어 집중, R3F 시각화와 FastAPI 사용.
- 추가 확정: 핵심은 다중 농장 전이학습·예측 신뢰도. 직접 센서 실측을 요구하지 않고 기존 데이터를 활용하며 시연은 시뮬레이터로만 진행한다.
- 구현 상태: 내부 공간·현재 상대 지수 히트맵·C1~C4 합성 재생·FastAPI 조회와 오류 처리.
- 아직 없는 것: 실제 예측/비전 모델 연결, 실측 환기 반응 보정, 실물 제어 통신, 실증 저감 성능.
- 내부 평가의 유력 주 비교는 C2 대 C3. C4의 추가 효과를 배출측 보조 지표로 남길지는 이번 회의에서 결정.

## 2. 핵심 결정 5개

| 번호 | 회의 질문 | 제안/선택지 | 결정에 필요한 근거 | 결정 기록 |
| --- | --- | --- | --- | --- |
| D1 | 주력 검증 기술 | 다중 농장 전이학습과 예측 신뢰도. 비전은 보조 | 사용자 추가 지시. 세부 모델·농장 데이터는 미정 | 방향 확정 |
| D2 | 비전 결과를 농도 예측의 입력으로 쓸 수 있는가? | 동일 돈사·시각의 대응 데이터가 있으면 융합 검토. 없으면 독립 탐지 시각화·별도 평가부터 진행 | 영상/센서 타임스탬프, 카메라/돈방 ID, NH₃ 관측 위치, 표면 오염 라벨 | 미정 |
| D3 | C1~C4를 어떤 역할로 제안서에 남길 것인가? | 권장: C2·C3 주 비교, C1 스트레스 참고, C4 배출 처리 보조. 내부 지표만 다룰 경우 C4는 확장 항목으로 설명하는 안도 있음 | 팬과 스크러버 계통, 과제 범위. 현재 코드는 C2 BASE→HIGH, C3=C4 실내 궤적 | 미정 |
| D4 | 출력 단위와 데이터 공급 규격은 무엇인가? | 현재 relative_index는 개발용으로 유지. 실제 데이터의 ppm 여부, 샘플 간격, 예측 기준 시각을 확인 후 계약 개정 | 실제 파일의 헤더·단위 설명·결측 예시·정상 샘플 | 미정 |
| D5 | 무엇을 성능 검증이라고 부를 것인가? | 예측 오차·피크 탐지와, 환경 반응 모델 안의 제어 결과를 분리. 실농장 저감 성과는 별도 근거가 있을 때만 기재 | 학습/평가 분할, 기준선, 반응 모델의 출처. 목표 수치와 기준값은 회의 후 확정 | 미정 |

권장 논의 순서: 주력 방향 D1 공유 → 확보 농장·기간 확인 → D4 → D5 → D3 → 보조 항목 D2. D1을 다시 선택할 필요는 없습니다. 타깃 농장 적응·보정·평가 구간과 모델 비교군을 구체화하면 됩니다.

## 3. 회의에 가져올 최소 자료

대규모 파일 전체보다 아래 정보와 작은 샘플이 먼저 필요합니다. 확보 여부를 각 담당자가 기록합니다.

아래 센서 자료는 기존에 수집·공개·제공된 파일을 뜻합니다. 팀에 신규 센서 설치나 현장 실측을 요구하는 목록이 아닙니다. 비전과 환기 자료가 없으면 그 제한을 기록하고 핵심 예측 검증을 우선합니다.

| 자료 | 최소 내용 | 확보 여부/담당 |
| --- | --- | --- |
| 센서 시계열 샘플 | 헤더, 짧은 연속 구간, 단위, 시간대, 샘플 간격, 결측 표시 | 미정 |
| 데이터 출처 설명 | 실제 보유/요청 중 구분, 농장·돈방 식별, 사육 단계, 사용 조건 | 미정 |
| 비전 샘플 | 영상 또는 이미지와 라벨 예시, 대상 클래스, 촬영 시각·위치 정보 유무 | 미정 |
| 예측 출력 샘플 | 기준 시각, 예측 대상 시각, 단위, 예측값, 실제값 제공 여부 | 미정 |
| 환기 정보 | PWM/RPM만 있는지, 풍량·운전 상태·제어 이력도 있는지 | 미정 |

문서에 적힌 데이터 품질 결론과 보유 상태는 팀의 조사 기록으로 취급합니다. 이번 작업에서는 원본 센서 파일이나 모델 학습 결과를 재검증하지 않았습니다. 발표연도와 실제 수집연도도 나누어 기록하세요.

## 4. 연결 규격 초안 — 현재 API를 바꾸기 전 확인

| 항목 | 초안 | 미확정 부분 |
| --- | --- | --- |
| 대상 식별 | 농장/돈사/돈방 ID를 구분 | 실제 ID 체계 |
| 시각 | 시간대가 있는 관측 기준 시각, 응답 생성 시각, 예측 대상 시각 분리 | 실제 수집 시간대와 간격 |
| 현재 NH₃ | 값과 단위를 함께 관리. 누락은 null | ppm인지, 상대 지수인지 |
| 예측 | 목표는 +30분. 점예측과 예측구간·모델 식별자·기준 시각을 제공하는 방향 | 구간 산출법·목표 포함률·평가 결과. 실제 구간은 아직 미구현 |
| 비전 | 탐지 클래스·촬영 시각·카메라 ID부터 정리 | 2D 좌표를 돈사 바닥 좌표로 변환할 수 있는지 |
| 면적 | 픽셀 면적과 m² 구분 | 카메라 보정·실척도 정보 확보 여부 |
| 히트맵 | 전체 지수에서 만든 표시와 위치별 예측을 구분 | 공간 관측이 있는지, 단순 배분으로 표시할지 |
| 장치 상태 | 명령값과 확인된 동작값을 구분 | 실측 로그 또는 모의 상태 중 무엇을 제공할지 |
| 데이터 출처 | 합성/실측/모델 예측을 구분 | 실제 공급 계약의 source 값과 버전 |

현재 API 1.0은 `synthetic-replay`, `relative_index`만 받습니다. 실제 모델 출력을 그대로 꽂는 계약이 아니므로, 위 내용 합의 후 서버 스키마와 프론트 검증을 함께 바꿔야 합니다. 지금 단계에서는 미래 규격을 코드에 임의로 확정하지 않습니다.

## 5. 평가 계획 초안 — 아직 수치 목표 없음

| 검증 대상 | 지표 후보 | 비교 조건에서 확인할 것 |
| --- | --- | --- |
| 예측 정확도 | MAE/RMSE, 피크 탐지 여부·선행 시간 | 실제값 존재, 시간 순서 분리, 평가 구간의 학습 유입 방지 |
| 모델 기준선 | 현재 관측값 유지(persistence), 단순 모델 | 같은 예측 시점·단위·평가 구간. 입력 지연과 예측 간격을 명시 |
| 예측 신뢰도 — 핵심 | 실제 포함률과 구간 폭, 농장별 결과 | 목표 포함률·구간 산출법 확정. 보정과 평가 구간 분리 |
| 내부 제어 | 피크, 기준 초과 시간, 누적 노출 지수 | 동일 발생원·초기조건, 제어 후 환경 반응 모델의 근거 |
| 제어 부담 | HIGH 유지시간, 전환 횟수 | 실제 전력 정보 없이는 kWh 절감으로 환산하지 않음 |
| C4를 보조로 유지할 경우 | 처리 전후 배출 상대량 | 실내 지표와 구분, 압력손실·제거율 가정 명시 |

피크·초과시간 기준은 현재 코드의 0.65를 실제 안전 기준으로 가져오지 않습니다. 실측 농도의 의미와 프로젝트 평가 목표를 정한 뒤 별도로 합의합니다. NH₃ 지표 개선을 모든 악취물질의 개선으로 일반화하지 않습니다.
